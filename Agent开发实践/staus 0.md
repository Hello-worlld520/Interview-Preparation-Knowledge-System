**chatbot、workflow、agent、multi-agent的区别**

```
【Multi-Agent】← 最高层（群体智能）
    └─ 内部由多个【Agent】组成
           └─ 如果这个Agent没有工具调用、路径固定，那它本质上是个【Workflow】
                    └─ 如果连固定路径都没有，只是纯对话，那就是个【Chatbot】
```

## 关于agent框架

个人认为应该持谨慎的态度，agent处于一个兴起繁荣的阶段，我觉得框架还处于一个层出不穷但不够稳定的状态，可能经过一段时间的大浪淘沙才会形成像Java一样相对比较完善的框架体系，就目前来说，我会尽量直接调用LLM的API，避免原本能够通过直接调用API的简单任务复杂化，如果要使用框架，在这之前我也会先弄清楚该框架的底层原理，避免在使用过程中带来由于框架原理不清导致的错误
